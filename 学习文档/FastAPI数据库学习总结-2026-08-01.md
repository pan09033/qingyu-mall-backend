# FastAPI 数据库学习总结

日期：2026-08-01

## 1. MySQL 基础操作

SQL 的四个核心操作：

```sql
-- 新增
INSERT INTO products (name, price, stock)
VALUES ('机械键盘', 299.00, 20);

-- 查询
SELECT * FROM products;

-- 修改
UPDATE products SET stock = 25 WHERE id = 1;

-- 删除
DELETE FROM products WHERE id = 1;
```

重点：修改和删除时要检查 `WHERE`，否则可能影响整张表。

Python 使用 PyMySQL 执行 SQL：

```python
cursor.execute(
    "UPDATE products SET stock = %s WHERE id = %s",
    (25, 1),
)
connection.commit()
```

- `%s` 是参数占位符。
- 单个参数元组要写成 `(1,)`。
- 短 SQL 可以用普通引号，长 SQL 可以用三引号。
- 三引号是 Python 多行字符串语法，不是 SQL 的要求。

## 2. SQLAlchemy ORM

ORM 的对应关系：

```text
Python类   → 数据库表
Python对象 → 表中的一行
对象属性   → 数据库字段
```

模型基本结构：

```python
class Product(Base):
    __tablename__ = "products"

    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String(30))
    price: Mapped[Decimal] = mapped_column(Numeric(10, 2))
    stock: Mapped[int] = mapped_column()
```

### 查询

```python
statement = select(Product)
products = session.scalars(statement).all()
```

- `statement` 是查询语句，不能直接遍历。
- `session.scalar(statement)` 获取一个结果或 `None`。
- `session.scalars(statement).all()` 获取多个结果。
- `session.get(Product, product_id)` 根据主键查询。

### 新增

```python
new_product = Product(name="显示器", price=899, stock=10)
session.add(new_product)
session.commit()
session.refresh(new_product)
```

### 修改

```python
product = session.get(Product, product_id)
product.stock = 20
session.commit()
session.refresh(product)
```

### 删除

```python
product = session.get(Product, product_id)
session.delete(product)
session.commit()
```

删除后对象已不在数据库中，不能再执行 `refresh()`。

## 3. FastAPI 接入数据库

项目职责划分：

```text
models       SQLAlchemy数据库表模型
schemas      Pydantic请求和响应模型
routers      API接口
database.py  engine、Base和Session依赖
```

每个请求使用独立 Session：

```python
def get_db() -> Generator[Session, None, None]:
    with Session(engine) as session:
        yield session
```

定义依赖类型：

```python
Database = Annotated[Session, Depends(get_db)]
```

FastAPI 会创建 Session、传给接口，并在请求结束后自动关闭。

## 4. 数据库 GET 接口

```python
@router.get("/", response_model=list[ProductResponse])
def get_products(db: Database):
    return db.scalars(select(Product)).all()
```

响应模型需要支持读取 ORM 对象属性：

```python
model_config = ConfigDict(from_attributes=True)
```

## 5. 数据库 POST 接口

数据转换过程：

```text
JSON → ProductCreate → Product ORM对象 → MySQL → ProductResponse
```

```python
@router.post("/", response_model=ProductResponse)
def create_product(product_data: ProductCreate, db: Database):
    new_product = Product(
        name=product_data.name,
        price=product_data.price,
        stock=product_data.stock,
    )

    db.add(new_product)
    db.commit()
    db.refresh(new_product)

    return new_product
```

## 6. 数据库 PATCH 接口

PATCH 使用字段可选的 `ProductUpdate`，不是 `ProductCreate`：

```python
product = db.get(Product, product_id)

if product is None:
    raise HTTPException(status_code=404, detail="商品不存在")

update_data = product_data.model_dump(exclude_unset=True)

for field_name, new_value in update_data.items():
    setattr(product, field_name, new_value)

db.commit()
db.refresh(product)
```

`exclude_unset=True` 表示只修改请求中实际传入的字段。

## 7. 容易混淆的名称

```python
Product       # SQLAlchemy模型类
product       # 一个商品对象或普通变量
ProductCreate # 创建请求模型
ProductUpdate # 修改请求模型
ProductResponse  # 响应模型
```

不要导入：

```python
from practice.database_practice import product
```

`practice/database_practice.py` 中的 `product` 只是循环变量，而且导入练习文件会执行其中的数据库操作。

## 核心口诀

```text
请求模型管输入，响应模型管输出；
ORM模型对应数据库表；
查询先select，新增先创建对象；
修改先查再改，删除先查再删；
有修改就commit，需要最新数据再refresh。
```
