## 1. 数据库分页与搜索

分页接口不只返回商品列表，还返回分页信息：

```json
{
  "items": [],
  "total": 0,
  "skip": 0,
  "limit": 10
}
```

核心查询：

```python
statement = select(Product)
count_statement = select(func.count(Product.id))

if keyword is not None:
    condition = Product.name.contains(keyword)
    statement = statement.where(condition)
    count_statement = count_statement.where(condition)

total = db.scalar(count_statement) or 0
items = db.scalars(
    statement.order_by(Product.id).offset(skip).limit(limit)
).all()
```

重点：

- 数据查询和总数查询必须使用相同的搜索条件。
- `offset()` 跳过数据，`limit()` 限制返回数量。
- `order_by()` 保证分页顺序稳定。
- `limit` 应限制在 `1～100`。
- 分页列表和单个商品查询不能使用相同路由。

## 2. 单个商品查询

```python
product = db.get(Product, product_id)

if product is None:
    raise HTTPException(
        status_code=404,
        detail="商品不存在",
    )
```

常用路由：

```text
GET /products/       分页查询
GET /products/{id}   查询单个商品
```

## 3. 数据库事务与异常处理

增删改成功时提交，失败时回滚：

```python
try:
    db.commit()
except SQLAlchemyError as error:
    db.rollback()
    raise HTTPException(
        status_code=500,
        detail="数据库操作失败",
    ) from error
```

核心规则：

```text
查询通常不需要 commit
增删改成功需要 commit
增删改失败需要 rollback
新增和修改后可用 refresh 获取最新数据
删除后不能 refresh
```

HTTP 状态码：

```text
201  创建成功
204  删除成功，响应体为空
404  数据不存在
422  请求参数校验失败
500  服务器或数据库操作失败
```

## 4. 环境变量与配置管理

真实项目不应把 MySQL 密码写死在代码中。

配置链路：

```text
.env
  ↓
Pydantic Settings
  ↓
DATABASE_URL
  ↓
SQLAlchemy engine
  ↓
MySQL
```

重要文件：

```text
.env          保存本机真实配置，不提交
.env.example  提供配置示例，不放真实密码
.gitignore    必须包含 .env
app/config.py 读取和校验环境变量
```

使用 `URL.create()` 可以正确处理密码中的 `@、:、/、#` 等特殊字符。

## 5. Alembic 数据库迁移

`Base.metadata.create_all()` 主要负责创建不存在的表，不能代替正式的表结构版本管理。

Alembic 用来记录数据库结构变化：

```text
修改SQLAlchemy模型
       ↓
生成迁移 revision
       ↓
检查 upgrade/downgrade
       ↓
执行 upgrade head
```

已经完成：

- 安装 `Alembic 1.18.5`。
- 执行 `alembic init migrations`。
- 配置 `migrations/env.py` 复用项目 engine。
- 设置 `target_metadata = Base.metadata`。
- 导入 Product，使模型注册到 metadata。
- 生成并检查基线迁移 `df348ae7c571`。
- 基线迁移为空，没有意外修改或删除表。

常用命令：

```powershell
python -m alembic current
python -m alembic revision --autogenerate -m "说明"
python -m alembic upgrade head
python -m alembic history
```
