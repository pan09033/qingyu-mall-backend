# FastAPI 今日学习总结

## 1. 请求模型与响应模型

- 请求模型：校验客户端传入的数据。
- 响应模型：校验、转换并过滤服务器返回的数据。

```python
class UserCreate(UserBase):
    pass


class UserResponse(UserBase):
    id: int
```

接口通过 `response_model` 指定响应结构：

```python
@router.post("/", response_model=UserResponse)
def create_user(user: UserCreate):
    ...
```

列表响应写成：

```python
response_model=list[UserResponse]
```

## 2. PATCH 部分更新

`PUT` 通常完整替换数据，`PATCH` 只修改客户端实际提供的字段。

```python
update_data = user_update.model_dump(exclude_unset=True)
stored_user.update(update_data)
```

`exclude_unset=True` 会排除请求中没有出现的字段。

## 3. 自定义字段校验器

`@field_validator` 用于实现 `Field` 无法表达的业务规则。

```python
@field_validator("name", mode="before")
@classmethod
def clean_name(cls, value: Any) -> Any:
    if not isinstance(value, str):
        return value

    cleaned_name = value.strip()
    if not cleaned_name:
        raise ValueError("用户姓名不能为空")

    return cleaned_name
```

重点：

- `mode="before"`：在Pydantic类型和长度校验前处理原始数据。
- `strip()`：删除字符串两侧空格。
- 校验失败抛出 `ValueError`，FastAPI通常返回422。
- 校验成功必须返回处理后的值。
- `isinstance(value, str)` 判断数据是不是字符串。

## 4. 依赖注入 `Depends`

依赖注入用于复用公共逻辑，例如分页、数据库连接和登录认证。

公共分页依赖：

```python
def pagination_parameters(skip: int = 0, limit: int = 10):
    return {"skip": skip, "limit": limit}
```

接口使用：

```python
pagination: Annotated[
    dict[str, int],
    Depends(pagination_parameters),
]
```

FastAPI会：

1. 读取并校验 `skip`、`limit`。
2. 自动调用依赖函数。
3. 把返回结果注入 `pagination`。

分页切片：

```python
return data[skip:skip + limit]
```

## 5. DELETE 删除接口

```python
for index, item in enumerate(items):
    if item["id"] == item_id:
        items.pop(index)
        return Response(status_code=204)
```

- `enumerate()` 同时提供列表索引和元素。
- `204 No Content` 表示成功但没有响应体。
- 数据不存在时使用 `HTTPException` 返回404。

## 7. 今日常见错误

- 把普通类当成Pydantic响应模型。
- `Annotated` 内部漏写逗号。
- 在 `Depends()` 中错误调用依赖函数。
- 参数名与依赖函数同名，造成名称覆盖。
- `skip`、`limit` 未从依赖结果中取出。
- 商品接口误用用户响应模型。
- 对整数调用 `strip()`。
- 校验器忘记返回处理后的值。
- 204响应错误地返回JSON内容。

```text

Depends管公共逻辑复用。
```
