- 移除不安全的旧用户写接口
- 将用户名和密码哈希设置为数据库 `NOT NULL`

## 四、第一阶段：pytest 自动化测试

这是下一项学习内容。

主要学习：

- `pytest` 基本语法
- 测试文件和测试函数
- FastAPI `TestClient`
- `assert` 判断测试结果
- fixture 准备和清理测试数据
- 使用独立测试数据库
- 覆盖注册、登录和 Token 测试
- 覆盖未登录、假 Token、过期 Token
- 覆盖订单所有权和越权测试

完成标准：

```powershell
pytest
```

执行一条命令，就能自动检查主要接口是否正常。

## 五、第二阶段：角色和管理员权限 RBAC

RBAC 是 Role-Based Access Control，即基于角色的权限控制。

主要学习：

- 给用户增加 `role` 字段
- 普通用户和管理员
- 创建 `get_current_admin` 依赖
- 普通用户只能管理自己的资料和订单
- 管理员可以查询用户列表、查看用户详情
- 无权限时返回 `403 Forbidden`
- 使用 Alembic 增加角色字段

需要分清：

```text
401：没有有效身份
403：身份有效，但权限不足
```

## 六、第三阶段：异常、日志和配置

### 统一异常处理

- 自定义业务异常
- 全局异常处理器
- 统一错误响应格式
- 减少每个接口重复写 `try/except`

### 日志

- Python `logging`
- 记录请求、错误和关键业务操作
- 不在日志中记录密码和完整 Token
- 区分开发日志和生产日志

### 多环境配置

- 开发环境
- 测试环境
- 生产环境
- 不同环境使用不同数据库和 JWT 密钥
- `.env` 和环境变量管理
